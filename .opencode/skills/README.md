# Скиллы проекта

Папка для скиллов OpenCode — готовых инструкций, которые я подгружаю
по необходимости, а не тащу в каждый запрос.

## Как устроено

```
.opencode/skills/
└── <имя-скилла>/
    ├── SKILL.md          ← сам скилл
    ├── scripts/          ← скрипты, если нужны
    └── references/       ← справочные файлы
```

Имя папки — это ID скилла. Чтобы я мог его подобрать сам, в `SKILL.md`
обязателен блок с описанием:

```markdown
---
name: Имя Скилла
description: Что делает скилл и когда его применять
---

Инструкции...
```

Пути внутри `SKILL.md` пишутся относительно папки скилла, поэтому
`references/что-то.md` и `scripts/что-то.py` подхватятся сами.

## Как использовать

- Скилл для всего проекта лежит здесь.
- Скиллы на все проекты — в `~/.config/opencode/skills`.
- Другие папки скиллов подключаются в `opencode.json` через поле
  `skills` (можно указать локальную папку или ссылку на HTTP-каталог).
- Загрузить скилл вручную: `@имя-скилла` в промпте.
